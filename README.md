# 🧪 Git Lab 01 — First Repository

My first Git & GitHub lab from the **ITI .NET track** (March 2026).

## What I practiced
- `git init` — create a local repository
- `git add` / `git commit` — stage and save changes
- `git remote add` / `git push` — publish the repository to GitHub

```bash
git init
git add name.txt
git commit -m "My Name"
git remote add origin https://github.com/Mohamed-Elhosinii/Lab01.git
git push -u origin master
```
